# Sprint-0-CSE-3902

The Sprint 0 project creates a window that resizes to the current monitors height and width. Then spawns the player character in the top left. You can move the player character with A,S,D, and Space.

A moves you left
D moves you right
S moves you down
and Space moves you up

When you click with the right mouse button a coin will instantly move to the mouse cursors position.

Pressing ESC or the back button will exit out of the game and close the window.
